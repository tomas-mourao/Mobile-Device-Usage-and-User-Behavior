# Mobile Device Usage and User Behavior Analysis

Group project analysing the *Mobile Device Usage and User Behavior* dataset with **Orange Data Mining**, following the **CRISP-DM** methodology.

> **Course:** Data in Science, Management and Society · BSc in Data Science, ISCTE · Year 1, Semester 1

## Methodology (CRISP-DM)
1. Business Understanding
2. Data Understanding
3. Data Preparation
4. Data Analysis
5. Modeling
6. Evaluation

## Tech stack
Orange Data Mining

## How to run
Install [Orange Data Mining](https://orangedatamining.com/) and open `orange_workflow.ows`.

## Project structure
| File | Description |
|------|-------------|
| `orange_workflow.ows` | Orange workflow |
| `report.docx` | Project report |

> The report is written in Portuguese.
